## 👨‍💻 About Me

Apasionado por el desarrollo de software, la creación de sistemas empresariales escalables y el desarrollo de soluciones tecnológicas de alto impacto. Mi experiencia abarca desde el **desarrollo Web Full-Stack (.NET, PHP, TypeScript)** hasta **sistemas embebidos e IoT (ESP32, Arduino)** y **aplicaciones móviles**.

- 🤖 Entusiasta de la robótica y el **Internet de las Cosas (IoT)**, creando interfaces entre hardware y APIs en la nube.
